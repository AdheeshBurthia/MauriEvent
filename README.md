# MauriEvent Final Year Project
<br>
The MauriEvent project's scope includes creating, implementing, and overseeing a mobile application intended to support Mauritius' event ecology. 
The project's main goal is to provide a comprehensive and approachable platform that meets the requirements of users, event organisers and administrators. 

User Platform
•	Users can explore and look up events taking place in Mauritius.
•	View the date, time, place, and descriptions of each event.
•	Integrated booking and ticket purchase features.
•	Show event locations on interactive maps.
•	Provide directions to various venues.
•	Set reminders for booked events.
•	Sync event dates and times with the device's calendar.
•	Photo and video galleries showcase highlights from past events.
•	Share event bookings and experiences on social media platforms directly from the app.
•	Provide a rating and review system for users to give feedback after attending events.
•	Direct communication with event organisers for inquiries and updates.

Organiser Platform
•	Tools for organisers to create, update, and manage events.
•	QR code scanning functionality is available for ticket validation at event entrances.
•	Add or delete images and videos related to events.
•	Manage event galleries and highlight content.
•	Process refunds for users.
•	View financial statistics such as total attendees, total bookings, and total tickets sold.
•	Access to detailed analytics and reports on event performance and attendee statistics.
